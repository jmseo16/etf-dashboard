# rx_l1 — 회차 0 (분류)

## 요약
- 상태: 끝남 (분류는 손으로 읽은 구조 분석, 자동 분류 도구 없음)
- 한 일: dq<7:0> 데이터, dqs 클럭, 출력 16 + wl_out, 제어 K1/K3/K4/K6/K8, 숨김 ddl(K7), 블록 역할 표, 질문 8개를 `snapshots/rx_l1/r0_a_classify/`(검토 전), `r0_c_review/`(검토 뒤)에 저장.
- 못 한 일과 이유: netlist 전체를 코드로 추적하지 않았다(기준 analyze.py 가 새 회로에서 깨짐). 큰 회로(트랜지스터 수백 개, 26 셀)라 일부 확신은 손으로 따라간 근거에만 의존.

## 분류
- 고속 데이터 입력: dq<7:0> / 고속 클럭 입력: dqs_t, dqs_c / 고속 출력: qr<7:0>, qf<7:0> / 상태 출력: wl_out
- 그리는 제어: odt_en, rtt<2:0> (K4, xi6/mp2.g), t1w<2:0>, t2w<1:0> (K1, xi30/xi4/mn12.g, mn22.g), vrc<5:0> (K6, xi2/mp11.g), rx_en (K3), slp (K3, mp0.g), gate_open (K3), wl_en (K3), wl_ck (K8, 낮음)
- 숨기는 제어: ddl<2:0> (K7, xi10/xi1/mn0.g), ibias, net203 (K11)
- 블록 역할 표: classification.md 참조. 질문 Q1–Q8.
- netlist 이상한 곳: ckbuf 병렬 출력 단락, 더미 슬라이스 xi38 (입력 전부 전원), 클럭선 안테나 다이오드

## 명세서·묶음에서 막힌 곳
- 가상 전원을 만드는 헤더 스위치(mp0)의 그림 규칙 없음, 같은 셀 반복(xi30..xi37)의 클럭 연결이 두 묶음으로 갈리는 경우, 단일 디지털 포트가 샘플링 대상일 때(wl_ck) 분류.
