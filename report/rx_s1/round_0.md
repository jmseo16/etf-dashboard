## 분류 (회차 0에서 채움)
- 고속 데이터 입력: PAD (ESD+종단), LB_P/LB_N (루프백 쌍, Q2) / 고속 클럭 입력: CK, CKB / 고속 출력: DOUT_E, DOUT_O
- 그리는 제어 (이름, K#, 끝점 핀):
  - RX_EN (K3, dfe_sum mn2 꼬리 스위치 / ck_gbuf NAND 입력)
  - LB_EN (K2, rx_pre sel_m·sel_l 선택)
  - ODT_EN (K4), RTT<2:0> (K4, 버스, DEC 박스 경유 → odt_pu 스위치 게이트)
  - TAP<3:0> (K1, dfe_sum 꼬리 가중 쌍, 버스)
  - TAP_SGN (K2, dfe_sum sgn/sgnb 극성 선택, 1줄)
- 숨기는 제어 (이름, K#): OFE_P/N<1:0>, OFO_P/N<1:0> (K7 일반 트림), IBIAS (K11)
- 블록 역할 표: esd_dq 종단·ESD (높음), odt_pu 종단 (높음), odt_dec DEC (높음), ls_lh LS (높음), rx_pre 일반 (낮음 → Q1), dfe_sum Summer (높음), sa_dt 비교기 StrongARM (높음), sr_nor SR latch (높음), ck_gbuf 복합 논리 (높음), rx_bias 생략 (높음)
- 질문과 가정한 답 (4개):
  - Q1 RX_PRE 사전에 없음 → 일반 박스
  - Q2 LB_P/LB_N 고속 데이터 입력(루프백) → 예
  - Q3 MN8/MN9 (S=D MOS 커패시터) → 의도됨, 그리지 않음
  - Q4 DFE 고리 → 복합 블록 "DFE 슬라이스"
- netlist에서 이상하다고 본 곳: rx_pre MN8/MN9 (S=D 단락), sa_dt의 S=D 커패시터형 트림 소자, esd_dq 클램프 게이트가 10k로 묶여 항상 꺼져 있음 (질문 안 함).

## 명세서·묶음에서 막힌 곳
- §2.5-3/§2.5-4: K4(종단 스위치 R)와 K5(병렬 다리 종단)의 경계가 ODT 병렬 R 다리에서 겹쳐 보임. 끝점 표 순서대로 K4로 정함.
- §2.6-복합 "고리" 예외: DFE 고리가 샘플러 데이터 입력을 거쳐 닫히므로 복합 블록으로 봤지만, SR 래치의 set/reset 경로가 고리에 들어 있어 예외 적용 여부가 애매했음. 복합 블록으로 가정.
- §2.6-1 ICG: ck_gbuf는 래치가 없는 NAND 게이트형이라 ICG 행과 맞지 않음. 논리 게이트 복합으로 처리.
