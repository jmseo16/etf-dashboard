# 분류 확인 표 — rxbyte_eq

고속 데이터 입력 : dq<7:0>
클럭 입력        : dqs_t, dqs_c
고속 출력        : qf<7:0>, qr<7:0>
중요 제어        : rx_en (K3), gate_open (K3), wl_en (K3), wl_ck (K9), slp (K3), odt_en (K4), rtt<2:0> (K4), vrc<4:0> (K2), t1w<3:0> (K1)
숨김             : pk<1:0> (K7), ddl<2:0> (K7), ibias (K11)
질문             : 1개

| 포트 | 분류 | 끝점 | 근거 | 그림 |
|---|---|---|---|---|
| `dq<7:0>` | 고속 데이터 입력 |  | 패드/차동쌍 → 입력 트랜지스터 → 샘플러 데이터 입력 | 그림 |
| `dqs_t` | 고속 클럭 입력 |  | 클럭 역할 게이트(꼬리·프리차지·latch 전달 게이트)에 도달 | 그림 |
| `dqs_c` | 고속 클럭 입력 |  | 클럭 역할 게이트(꼬리·프리차지·latch 전달 게이트)에 도달 | 그림 |
| `qr<7:0>` | 고속 출력 (고속 데이터) |  | 고속 추적이 닿는 출력 | 그림 |
| `qf<7:0>` | 고속 출력 (고속 데이터) |  | 고속 추적이 닿는 출력 | 그림 |
| `wl_out` | 상태 출력 | O1 | 안에서 구동, 고속 추적이 닿지 않음 | 그림 |
| `rx_en` | 중요 제어 — 켜기/끄기 | K3 | 고속 경로의 게이트/꼬리 스위치 | 그림 |
| `gate_open` | 중요 제어 — 켜기/끄기 | K3 | 고속 경로의 게이트/꼬리 스위치 | 그림 |
| `wl_en` | 중요 제어 — 켜기/끄기 | K3 | 고속 경로의 게이트/꼬리 스위치 | 그림 |
| `wl_ck` | 중요 제어 — 시험 입력 | K9 | 출력 포트로만 감 | 그림 |
| `slp` | 중요 제어 — 켜기/끄기 | K3 | 전원 스위치(헤더/풋터) | 그림 |
| `odt_en` | 중요 제어 — 종단 | K4 | 패드로 가는 R의 직렬 스위치 | 그림 |
| `rtt<2:0>` | 중요 제어 — 종단 | K4 | 패드로 가는 R의 직렬 스위치 | 그림 |
| `vrc<4:0>` | 중요 제어 — 경로 선택 | K2 | 양쪽 극성으로 경로를 고름(선택) | 그림 |
| `t1w<3:0>` | 중요 제어 — 가중치(탭 계수) | K1 | 합산 가지(차동쌍 아래 스위치) | 그림 |
| `pk<1:0>` | 일반 제어 — 트림(정적) | K7 | 안쪽 노드에 C를 붙이는 스위치(정적 트림) | 숨김 |
| `ddl<2:0>` | 일반 제어 — 트림(정적) | K7 | 같은 신호의 지연 탭 선택(정적 지연 트림) | 숨김 |

## 질문과 가정한 답

- **ctl:wl_ck** — 포트 wl_ck: 고속 클럭으로 샘플되어 관찰용 출력으로만 갑니다(데이터 입력처럼 쓰임). 시험 입력으로 한 줄 그립니다.  
  선택지: K9 / K8 / hs_data / hs_clock  
  가정한 답: **K9**
