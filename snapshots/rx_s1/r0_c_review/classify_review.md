# 분류 검토 — rx_s1 (DQ_RX_UNIT), 회차 0
검토자: 같은 모델(Claude 역할, prompts/claude_2_review_classify.md). 입력: 분류 표·사전 대응·질문·netlist 구조 (그린 쪽 GLM 결과와 같은 모델).

## (a) GLM이 고칠 목록
1. `classification.md`의 "ICG 계열(ck_gbuf는 논리 게이트 복합)" 문구: ck_gbuf는 래치가 없어 사전의 ICG가 아니다. 사전 행은 "복합 블록 (논리 게이트만)"으로 정정. (근거: netlist `ck_gbuf` = nand2_c ×2 + inv_c ×2, 명세서 §2.6-1 복합 블록 행)
2. 나머지 분류는 구조 근거와 맞음 — 고칠 것 없음 (K1/K2/K3/K4/K7/K11 분류, vref 기준 전압, 고속 입력 판정 확인).

## (b) 사용자 질문 (최대 10개) — 이번 회차 4개
1. **[block_role] RX_PRE**: 입력쌍 2개(PAD쪽·루프백쪽)를 sel_m/sel_l로 바꾸는 프리앰프는 사전에 없음. 일반 박스로 그려도 됩니까? (일반 박스 / 사전 행 지정)
   - 가정한 답: 일반 박스 "PRE (입력 선택)"
2. **[fast_input] LB_P, LB_N**: 루프백 차동 쌍을 고속 데이터 입력으로 둡니까? (데이터 입력 / 제어 / 기타)
   - 가정한 답: 고속 데이터 입력(루프백)
3. **[netlist_error] RX_PRE MN8, MN9**: 게이트가 입력, 드레인·소스가 단락된 MOS 커패시터입니다. 의도된 것입니까? (의도됨 / netlist 오류)
   - 가정한 답: 의도됨. 그리지 않고 생략 목록에 "C" 한 줄
4. **[block_role] DFE 슬라이스 고리**: dfe_sum → sa_dt → sr_nor → dfe_sum 고리를 복합 블록 "DFE 슬라이스"로 그립니까? (복합 / 일반 박스)
   - 가정한 답: 복합 블록

## (c) 묻지 않고 가정한 답으로 둔 것
- 미사용 출력 net27, net29 → 짧은 선 + 이름표 (규칙)
- K4(종단)와 K5(병렬 다리) 경계 → K4 (끝점 표 위 순서)
- 오프셋 트림 OFE/OFO → K7 일반, 숨김 (포트 출처)
- IBIAS → K11 바이어스, 숨김. RX_BIAS 블록 생략
- 사전 목록 기호 (INV/NAND/NOR/SR latch/LS) → 질문 없음
- 버스 표기 `<n>` 그대로 → 질문 없음
