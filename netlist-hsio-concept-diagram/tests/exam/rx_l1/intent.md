# rx_l1 설계 메모 (채점용 — 시험 보는 쪽에 주지 않는다)

시험용으로 만든 가상 회로다. 최상위 셀 `rxbyte_top`, MOS 1211개, 셀 26개.
DRAM 쪽 쓰기 수신 1바이트: DQ 8개 + DQS/DQSB. DQS는 게이트·지연·트리를 거쳐 각 DQ 샘플러를 클럭한다.

## 신호 흐름

```
dqs_t/dqs_c ─ ESD ─ ODT ─ dqsrx [ 차동 amp → AC 결합 자기바이어스 amp ×2 → CCI → 버퍼 ] ─ net210/211
   ─ dqsgate [ latch ×2 + NAND + INV : 글리치 없는 클럭 게이트, enable = gate_open ] ─ net212/213
   ─ dly3 ×2 [ 2진 가중 지연선 3비트, ddl2..0 ] ─ net214/215 ─ 루트 버퍼 ─ net216/217
        ├─ 병렬 버퍼 2개 ─ net218/219 → DQ0–3
        ├─ 병렬 버퍼 2개 ─ net220/221 → DQ4–7
        └─ 버퍼 1개     ─ net222/223 → 더미 슬라이스, wldet

dqN ─ ESD ─ ODT ─ sbamp ×2 (자기바이어스 차동 amp, 교차 연결로 의사 차동; 다른 입력 = vref)
   ─ sadfe ×2 (StrongARM + 내장 2탭 DFE; 상승 = ckt, 하강 = ckc) ─ srnand ×2 ─ 버퍼 ─ qrN, qfN

vrc5..0 ─ vrefdac (PMOS 2진 전류 DAC → R → RC) ─ net204 = vref (9개 슬라이스 공유)
odt_en, rtt2..0 ─ odtctl (NAND + 레벨 시프터) ─ net207/206/205 → 패드 10개의 ODT 다리
wl_ck ─ wldet (DFF의 D 입력, 클럭 = aux 가지 DQS, wl_en으로 게이트) ─ wl_out
slp ─ PMOS 헤더 mp0 ─ net200 (가상 전원, 슬라이스 9개의 vdd)
```

## 포트 (설계 의도 ↔ 명세서 v6.1 분류)

| 포트 | 의도 | 명세서 분류 | 그림 |
|---|---|---|---|
| `dq7`..`dq0` | DQ 패드 | 고속 데이터 입력 ×8 (버스 `dq<7:0>`) | 선 (슬라이스 합치기) |
| `dqs_t`, `dqs_c` | 차동 스트로브 패드 | 고속 클럭 입력 | 선 |
| `qr7`..`qr0`, `qf7`..`qf0` | 상승·하강 에지 판정 데이터 | 고속 데이터 출력 | 선 |
| `wl_out` | write leveling 결과 (DFF 출력) | 상태 출력 O1 | 실선 + 출력 포트 |
| `wl_ck` | DQS로 샘플되는 시스템 클럭 | 구조는 고속 클럭 DFF의 **데이터 입력** — 이름은 클럭. 낮은 확신, 질문 대상 | 한 줄 (wldet로) |
| `wl_en` | wldet 클럭 게이트 enable | 중요 K3 | 한 줄 |
| `gate_open` | DQS 게이트 열기 | 중요 K3 (latch를 거쳐 고속 클럭 게이트) | 한 줄 |
| `rx_en` | 수신기 켜기 (레벨 시프터 경유) | 중요 K3 | 한 줄 |
| `slp` | 슬라이스 전원 차단 헤더 | 중요 K3 (고속 블록의 전원 스위치) | 한 줄 |
| `odt_en`, `rtt2..0` | 종단 켜기·세기 | 중요 K4 | 버스, `odtctl`은 DEC 박스 |
| `vrc5..0` | 기준 전압 레벨 코드 | 중요 K6 | 버스, `vrefdac`은 "VREF" 박스 |
| `t1w2..0`, `t2w1..0` | DFE 1탭·2탭 가중치 (세그먼트 enable) | 중요 K1 (버스 두 개) | 버스 |
| `ddl2..0` | DQS 지연 코드 (정적) | K7, 출처 포트 → 일반 | **숨김** (경계: 아래 7번) |
| `ibias` | 기준 전류 | 바이어스 K11 | 숨김 |
| `vdd`, `vddq`, `vss`, `vssq` | 전원 | 전원 | 숨김 |

## 셀 역할

| 셀 | 역할 | 사전 행 |
|---|---|---|
| `padesd` | ESD | 종단·ESD |
| `odtleg3` | 종단 다리 3개 | 종단 |
| `odtctl` | NAND + 레벨 시프터 | DEC 박스 |
| `biasgen` | 미러 | 바이어스 — 생략 |
| `vrefdac` | 전류 DAC + R + RC | VREF 박스 |
| `dqsamp` | R 부하 차동쌍 | 증폭기(버퍼) |
| `acamp` | 직렬 C + 귀환 R 인버터 + 인버터 | AC 결합 자기바이어스 버퍼. "TIA" 행(귀환 R 증폭기)과 닮음 — 사전 대응은 낮은 확신 |
| `dqsrx` | 위 둘 + CCI + 버퍼 | 복합(클럭 수신) |
| `dqsgate` | latch 2개 + NAND + INV | ICG ×2 |
| `dly3` | 지연 버퍼 + TG MUX 3단 | 지연 셀(DLY) |
| `ckbuf` | 인버터 2개 | 클럭 버퍼 |
| `sbamp` | 자기바이어스 차동 amp (Bazes형): N쌍 + P쌍, 꼬리 게이트 = 한쪽 드레인 | 사전에 없음 — 일반 박스 + 질문 |
| `sadfe` | StrongARM + 탭 쌍 5세그먼트 (입력쌍과 병렬) | 비교기·샘플러 (Σ 박스가 따로 없음) |
| `srnand` | NAND SR latch | SR latch |
| `dqslice` | 1비트 수신 | 복합(반복 단위) |
| `wldet` | 클럭 게이트 + DFF + 버퍼 | 복합 |
| `lat_tg`, `dfftg`, `mux2tg`, `lvlup`, `dlybuf` | latch, DFF, MUX, LS, 지연 | 사전 |

## 일부러 넣은 것 (함정)

1. **비트 표기가 숫자 꼬리**: `dq7`, `vrc5`, `t1w2`, `rtt2` — 괄호가 없다. §2.5-7로 버스로 묶되 표기 추측이라 낮은 확신. `t1w*`와 `t2w*`는 줄기가 다른 두 버스다. `dqs_t`/`dqs_c`는 버스가 아니라 차동쌍이다. `sadfe` 핀은 `w1_2` 꼴이다.
2. **R·C에 값이 없다**: `rppolywo`, `rppolyhri`, `mimcap_2p0` 모델 이름과 W/L만 있다. 설명 문구에 Ω을 지어 쓰면 안 된다.
3. **자기바이어스 차동 amp `sbamp`**: 정적 CMOS 게이트 규칙으로 보면 "헤더·풋터가 달린 인버터"처럼 읽힌다. 두 개를 입력을 바꿔 달아 의사 차동 출력을 만든다(`xi2`: 패드→+, `xi3`: 패드→−).
4. **DFE가 샘플러 안에 있다**: `sadfe`의 탭 쌍이 입력쌍 드레인(net85/86)에 병렬로 붙고, 세그먼트마다 코드 스위치(`mn12`, `mn15`, …)를 거쳐 클럭 꼬리에 닿는다. 1탭 입력 = 반대 위상 SR 출력, 2탭 입력 = 같은 위상 자기 SR 출력.
5. **AC 결합 자기바이어스 amp `acamp`**: 직렬 MIM C + 귀환 R이 달린 인버터. 꺼짐 풋터(`mn1`)와 풀업(`mp1`)이 있다.
6. **CCI**: `dqsrx`의 `xi3`/`xi4`가 두 위상 사이 cross-coupled 인버터다(§3.3-7, §4.1-12 배치 규칙 대상).
7. **지연선 코드 `ddl2..0`**: 단마다 "우회/지연"을 TG MUX로 고르는 2진 가중 지연선이다. 의도는 같은 지연 소자의 탭 선택 = K7 정적 → 숨김. "지연/비지연 경로 선택 = K2"로 읽어 그렸다면 그린 쪽 잘못이 아니라 **명세 경계**로 기록한다.
8. **병렬 버퍼**: `xi14`/`xi15`처럼 입력·출력이 같은 `ckbuf` 두 개는 버퍼 하나(×2)다.
9. **더미 슬라이스 `xi38`**: 패드는 `vssq`, enable 꺼짐, 코드 접지, ODT 꺼짐, 출력(`net224`, `net225`) 미연결. 클럭 부하 맞춤용이다. 고속 입력이 아니며, 그리지 않고 생략 목록에 적는 것이 의도다.
10. **가상 전원 `net200`**: PMOS 헤더 `mp0` 뒤 넷이 슬라이스의 `vdd`다. §2.1-1(PMOS 벌크에 쓰인 넷은 전원)로 전원이다. 신호선으로 그리면 틀린다.
11. **안테나 다이오드 `d0`, `d1`**: 클럭 넷에서 `vss`로 가는 작은 다이오드. 패드가 아니므로 ESD가 아니다. 생략.
12. **`wl_ck`**: 이름은 클럭인데 구조는 DFF 데이터 입력이다. 질문이 나와야 한다.
13. **VREF 발생기**: 저항 사다리가 아니라 전류 DAC다. 고정 가지 `mp12`/`mp13`의 스위치는 게이트가 `vssq`라 항상 켜져 있다.
14. **ODT 제어 공유**: `odtctl` 하나가 패드 10개(DQ 8 + DQS 2)를 맡는다. 레벨 시프터 `outb`(net28–30)는 미사용.
15. **최상위 내부 넷 이름이 전부 `netNNN`**.

## 채점 때 볼 것

- 최상위 블록도: DQS 경로(수신 → 게이트 → 지연 → 트리)와 DQ 슬라이스 ×8(합쳐서 한 블록 ×8, 니블 클럭 구분), VREF 박스, ODT DEC, wldet. 교차 0.
- 그리는 제어: `rx_en`, `gate_open`, `slp`, `wl_en`, `odt_en`/`rtt`, `vrc`, `t1w`, `t2w`. 숨기는 것: `ddl`, `ibias`, 더미, 안테나 다이오드, 바이어스.
- 질문에 나와야 할 것: 숫자 꼬리 버스 표기, `wl_ck`, `sbamp`(사전에 없음), `acamp`(TIA 닮음).
- 슬라이스 하위 화면: sbamp ×2 → sadfe ×2 → SR ×2, 탭 귀환 4쌍(1탭 교차, 2탭 자기).
- 유닛 화면: `sadfe` StrongARM 교과서 배치 + 탭 세그먼트 합치기, `sbamp` 대칭, CCI 배치.
