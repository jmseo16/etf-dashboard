# rx_s1 설계 메모 (채점용 — 시험 보는 쪽에 주지 않는다)

시험용으로 만든 가상 회로다. 최상위 셀 `dq_rx_unit`, MOS 198개, 셀 16개.
POD(풀업 종단) 단일 종단 DQ 수신 1비트: 패드 → 센스앰프 출력(짝/홀 2위상)까지.

## 신호 흐름

```
pad ─ ESD(1차 다이오드, 150Ω, 2차 다이오드+GGNMOS) ─ net1 ─┐
pad ─ ODT 풀업 3다리(240/120/60Ω, VDDQ)                     │
vref ─ 5kΩ + MOS C (저역통과) ─ net3 ───────────────────────┤
lb_p/lb_n (루프백 차동 입력) ───────────────────────────────┤
                                                rx_pre (프리앰프, 차동쌍 2개가 부하 공유)
                                                      │ net6/net7
                         ┌────────────────────────────┴───────────────────────────┐
                 dfe_sum (짝, xi26)                                        dfe_sum (홀, xi27)
                 탭 입력 = 홀 SR 출력 net16/17                             탭 입력 = 짝 SR 출력 net14/15
                         │ net10/11                                               │ net12/13
                 sa_dt (xi28, 클럭 net8)                                   sa_dt (xi29, 클럭 net9)
                         │ net18/19                                               │ net24/25
                 sr_nor (xi30) → net14/15                                  sr_nor (xi31) → net16/17
                         │                                                        │
                 inv_a + inv_c → dout_e                                    inv_a + inv_c → dout_o
ck/ckb ─ ck_gbuf (NAND 게이트 + 인버터, enable = rx_en) ─ net8(짝), net9(홀)
```

## 포트 (설계 의도 ↔ 명세서 v6.1 분류)

| 포트 | 의도 | 명세서 분류 | 그림 |
|---|---|---|---|
| `pad` | DQ 패드 (ESD + 종단) | 고속 데이터 입력 | 선 |
| `lb_p`, `lb_n` | Tx에서 오는 루프백 차동 데이터 | 고속 데이터 입력 (차동 포트 쌍) | 선 |
| `ck`, `ckb` | 샘플 클럭 (짝/홀) | 고속 클럭 입력 | 선 |
| `dout_e`, `dout_o` | 짝/홀 판정 데이터 | 고속 데이터 출력 | 선 |
| `vref` | 판정 기준 전압 | 기준 (§2.5-6 기준 전압) | 회색 실선, 프리앰프 둘째 입력 |
| `lb_en` | 패드 ↔ 루프백 선택 | 중요 K2 | 선택까지 한 줄 |
| `rx_en` | 프리앰프·summer 꼬리, 클럭 게이트 | 중요 K3 | 한 줄 |
| `odt_en`, `rtt<2:0>` | 종단 켜기·세기 | 중요 K4 | 버스(+1줄), `odt_dec`는 DEC 박스 |
| `tap<3:0>` | DFE 1탭 가중치 (2진 전류 DAC) | 중요 K1 | 버스 |
| `tap_sgn` | 탭 부호 (스왑 스위치 4개) | 중요 (K1 가중치의 부호. K2로 그려도 그리기만 하면 됨) | 한 줄 |
| `ofe_p<1:0>`, `ofe_n<1:0>`, `ofo_p<1:0>`, `ofo_n<1:0>` | 센스앰프 오프셋 트림 (MOS C 스위치) | K7, 출처 포트 → 일반 | **숨김** (생략 목록) |
| `ibias` | 기준 전류. 다이오드 노드가 곧 summer 꼬리 게이트 | 바이어스 K11 | 숨김 |
| `vdd`, `vddq`, `vss`, `vssq` | 전원 | 전원 | 숨김 |

## 셀 역할

| 셀 | 역할 | 사전 행 |
|---|---|---|
| `esd_dq` | ESD (1차·2차 다이오드, 직렬 R, GGNMOS) | 종단·ESD |
| `odt_pu` | 종단 다리 3개 (PMOS 스위치 + R, 2진 가중) | 종단 (가변 종단 R) |
| `odt_dec` | NAND 3개 + 레벨 시프터 3개 | DEC 박스 (K4를 만듦) |
| `ls_lh` | 레벨 시프터 (cross-coupled PMOS — latch 아님) | LS |
| `rx_bias` | 전류 미러 + 꺼짐 스위치 | 바이어스 — 생략 |
| `rx_pre` | 프리앰프: 주 차동쌍(패드 vs vref) + 루프백 차동쌍, R 부하 공유, 꼬리 스위치로 선택 | 사전에 딱 맞는 행 없음(증폭기 + 입력 선택) — 일반 박스나 증폭기 삼각형 + 질문 가능 |
| `dfe_sum` | 합산기: 주 차동쌍 + 탭 차동쌍 → 같은 R 부하 | Summer (Σ) |
| `sa_dt` | double-tail 센스앰프 (1단: 클럭 꼬리 + 입력쌍 + 프리차지, 2단: PMOS 꼬리 + cross-coupled) | 비교기·샘플러 |
| `sr_nor` | NOR SR latch | SR latch |
| `ck_gbuf` | NAND 클럭 게이트 + 인버터 ×2 | 클럭 버퍼(게이트 포함) |

## 일부러 넣은 것 (함정)

1. **double-tail 센스앰프**: StrongARM이 아니다. 2단 PMOS 꼬리의 클럭은 셀 안 인버터(`xi0`)가 만든 반전 클럭이다. 리셋 때 출력이 low라 SR latch가 NOR형이다.
2. **중화 커패시터**: `rx_pre`의 `mn8`, `mn9`는 드레인=소스인 MOS 커패시터다(입력 게이트 ↔ 반대쪽 출력). cross-coupled 쌍이 아니다.
3. **루프백 선택에 MUX 셀이 없다**: 차동쌍 두 개가 부하를 공유하고 꼬리 스위치(`mn2`, `mn6`)로 하나를 고른다. `lb_en` → 인버터·NAND·인버터 → 꼬리 스위치.
4. **짝/홀 교차 귀환**: 짝 summer의 탭 입력은 홀 SR 출력, 홀 summer의 탭 입력은 짝 SR 출력이다. 귀환 선이 그림에 보여야 한다.
5. **탭 부호 스왑**: `dfe_sum`의 `mn6`–`mn9` 네 개가 탭 쌍 드레인을 바로/엇갈려 잇는다.
6. **오프셋 트림**: `sa_dt`의 `mn7`–`mn14` (스위치 + 접지 MOS C). 정적 코드라 숨긴다. 그리면 정책 위반.
7. **vref 저역통과**: `r0`(5k) + `mn0`(MOS C). vref는 데이터가 아니라 기준이다. 프리앰프는 의사 차동쌍(§2.3-11).
8. **부하 맞춤 더미 인버터**: `xi9`(net15→net27), `xi12`(net17→net29)는 출력이 아무 데도 안 간다. 미사용 출력 규칙(§3.5-4) 대상.
9. **GGNMOS 게이트가 R로 접지**: `esd_dq`의 `mn0` 게이트는 전원에 직접 묶이지 않고 10k를 거친다. 그래도 ESD다.
10. **최상위 내부 넷 이름이 전부 `netNN`**: 이름에 기댈 수 없다.
11. **`ibias` 포트가 꼬리 게이트에 직접**: summer 두 개의 `vbn` 핀이 `ibias` 넷이다.

## 채점 때 볼 것

- 고속 입력 3종(`pad`, `lb_p/lb_n`)과 클럭(`ck/ckb`)을 구조로 찾았나.
- 최상위 블록도: ESD/종단 표시 → 프리앰프 → Σ ×2 → 샘플러 ×2 → SR ×2 → 출력, 클럭 게이트, 귀환 두 줄, VREF 회색선.
- 그리는 제어: `tap<3:0>`, `tap_sgn`, `lb_en`, `rx_en`, `odt_en`/`rtt<2:0>`. 숨기는 제어: `of*` 8비트, `ibias`.
- 유닛 화면: `sa_dt` 교과서 배치(1단 아래, 2단 위 또는 좌우), `dfe_sum` 대칭, `rx_pre` 대칭(쌍 2개).
- 연결: 그림에서 다시 읽은 연결이 netlist와 같은가(특히 귀환의 P/N 극성).
