# 그리기 도구 시험 세트 (6종)

`hsio_draw`를 고칠 때마다 돌리는 회귀 시험 netlist다. 모두 시험용으로 만든 가상 회로다(실제 설계 아님).

| 폴더 | 회로 | 최상위 셀 | MOS |
|---|---|---|---|
| `rx_s4` | DQ 수신 1비트: 저항으로 묶인 입력쌍, 부호 전환 DFE 합산기, 오프셋 트림 샘플러 | `dqrx_eq` | 약 200 |
| `rx_s5` | DQ 수신 1비트: 제어 블록, 전원 헤더 스위치, 전송 게이트 MUX, 밑줄 표기 버스 | `dqrx_slice` | 225 |
| `rx_l4` | 수신 1바이트: 8DQ + DQS, 저항 사다리 + 선택 트리 기준 전압, CTLE | `rxbyte_eq` | 약 1,300 |
| `tx_s1` | DQ 출력 드라이버 1개: 레벨 시프터, 프리드라이버, ZQ 다리, 슬루 트림, 디엠퍼시스, ODT | `dq_tx_unit` | 343 |
| `tx_s2` | 직렬화기 + 클럭 경로: 클럭 수신, 듀티 보정, 2분주, 4:1 직렬화기, 루프백 | `txser4_top` | 303 |
| `tx_l1` | 송신 1바이트: DQ 8레인 + DQS 레인, 클럭 트리, ZQ 코드 분배, 더미 레인 | `txbyte` | 2,094 |

- 수신 3종은 5회차 모델 시험에 쓴 10개에서 구조가 가장 덜 겹치는 것을 고른 것이다.
- 송신 3종은 도구를 만든 쪽과 분리된 생성 에이전트가 썼다. 채점용 출제 의도는 이 폴더에 두지 않는다.
